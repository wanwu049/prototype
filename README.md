# 英圈刷题

一个面向英语学习的移动端网页原型，围绕 AI 学习诊断、刷题训练、拍照批阅、口语陪练与学习社区等场景设计。

## 功能页面

- 首页推荐、考试分类与搜索
- AI 诊断、专项练习、拍照答题与错题本
- 口语训练、语伴匹配和聊天室
- 学习社区、内容发布、评论与个人中心
- 订单、会员、优惠券与售后流程

## 本地查看

无需安装依赖，直接用浏览器打开 `index.html` 即可。页面之间通过普通链接跳转。

## 技术栈

- HTML
- CSS
- JavaScript

```text
index.html       首页
```
